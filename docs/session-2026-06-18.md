# Session Summary — 2026-06-18

## What was done

### Employees feature (`/admin/employees`)
- New `employee_profiles` table: `firstName`, `lastName`, `photo` (base64), `position`, `details`, `salary`, `salaryType` (monthly/daily/hourly), `hireDate`, `notes` (admin-internal)
- `salary_type` enum added to DB
- **List page** — avatar, name, position, email, salary in a clean table. "+ Add employee" button.
- **Create page** (`/new`) — full form: photo upload, first/last name, email, password, position, details, hire date, salary + type, admin notes. Creates user record + employee_profile in one action.
- **Edit page** (`/[id]`) — same fields as create. Three sections: profile form, change password, deactivate/reactivate.
- Salary is admin-only (page is admin-gated).
- `PhotoUpload` component — click to upload, preview, remove. Stores as base64 hidden field.

### Daily Duty feature (`/admin/duty`)
- New `daily_duty` table: `userId`, `date`, `notes`, `updatedBy` — unique constraint on `(userId, date)`.
- **Checkbox form** — staff sees all active users as checkboxes, selects who's on duty, submits once. Bulk-inserts all selected rows.
- **Roster view** — shown after first submission. Read-only for staff. Admin gets: edit note, remove entry, "+ Add more staff" expandable form.
- `duty` added to `STAFF_DEFAULT_MODULES`.
- `employees` module is admin-only.
